# 简历提取最小修复验证

## 范围

针对远端真实简历出现的“技能引文未通过校验”和“技能补充失败但原因不明确”，本轮仅调整 TypeScript 提取器及回归测试。

- 主提取、项目补充、技能补充复用同一 JSON 解析，兼容外围 Markdown JSON 代码块。
- 技能补充仅对网络、超时和 HTTP 429/500/502/503/504 重试一次；每次请求计入原有调用预算，取消后不继续请求。JSON、Schema、主体不明确及永久 HTTP 错误不重试。
- 技能补充失败使用现有任务警告保存阶段、错误码，以及适用时的 HTTP 状态或校验问题数量；保留主档案，不保存异常消息或模型响应。
- 引文失败在候选警告中保存块不可用、空引文、无法精确匹配、过长引文的计数及最大长度；不保存失败原文或模型生成的块 ID。计数针对当前校验项，重复诊断去重，并非全任务总计。块不可用也可能是上下文授权校验拒绝，不代表解析器漏块。
- 原文精确匹配、主体归属和 500 字引文上限不变；不凭空补入技能。
